# SKILL: 产品研究增强 — 麦格教授专属

## 触发条件

以下场景激活本技能：
- CEO 提出新产品方向，需要市场调研
- 需要做竞品分析或功能对比
- 需要梳理用户旅程和体验地图
- 需要设计产品流程或信息架构
- 需要制定版本迭代计划

## 增强能力 1：竞品分析

### 使用 web-search + browser-automation

1. **搜索竞品** — WebSearch 搜索关键词、行业报告
2. **深入分析** — WebFetch 获取竞品官网、功能页面
3. **截图对比** — browser-use 截取竞品界面关键页面
4. **整理报告** — 输出结构化竞品分析报告

## 增强能力 3：数据驱动产品决策

### 数据来源

- 飞书多维表格（用户反馈、需求池）
- Excel 数据分析（使用 excel-data 技能）
- 内容数据（卢娜的内容复盘数据）
- 销售数据（弗雷德的漏斗数据）
- 客户反馈（多比的满意度数据）

### 决策框架

| 指标 | 权重 | 评估方法 |
|------|------|----------|
| 用户价值 | 40% | 影响用户数 × 频率 × 痛点强度 |
| 商业价值 | 30% | 预期收入增长 / 成本降低 |
| 实现成本 | 20% | 赫敏评估的开发工时 |
| 风险 | 10% | 斯内普评估的技术和业务风险 |

## 增强能力 4：产品文档体系

### 文档层级

```
产品文档/
├── 产品愿景.md          # 长期方向
├── 版本路线图.md        # 季度/月度迭代计划
├── PRD/                 # 产品需求文档
│   ├── PRD-{编号}.md
│   └── ...
├── 验收标准/            # 验收检查表
├── 用户研究/            # 画像、旅程图、调研报告
└── 竞品分析/            # 竞品报告
```

### PRD 标准结构

1. 背景与目标
2. 用户故事
3. 功能清单（分优先级 P0/P1/P2）
4. 交互流程（配合 workflow-diagram-render）
5. 验收标准（每个功能可测试的标准）
6. 非功能需求（性能、安全、兼容性）
7. 里程碑和排期
