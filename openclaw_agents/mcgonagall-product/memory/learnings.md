# 麦格教授（产品部）长期记忆

---
_2026-04-10 02:00_ 【当前项目】ONES 需求审核自动化 - 产品视角

## 业务流程
1. 业务人员在飞书多维表格（稳健集团·数字化需求&BUG收集池）提交需求
2. Agent 扫描"待审批"记录，向审核人（CEO 李原野）推送飞书审核卡片
3. CEO 在飞书点击"通过"或"退回"
4. 通过：自动在 ONES 创建业务需求/问题缺陷工作项，回写链接到飞书表格
5. 退回：回写退回理由，通知提报人

## 字段映射
- 提报类型：需求优化 → 业务需求；系统BUG → 问题缺陷
- 所属产品：全棉WMS/医疗WMS/TMS/SAP/OMS/OA 等 8 个
- 需求优先级：高/中/低（仅需求优化）
- 严重程度：P0-P3（仅系统BUG）
- 状态流转：待审批 → 已提交ones / 退回需求

## 验收标准
- 完整闭环：从飞书提交到 ONES 建单全自动
- 回写准确：飞书表格的链接、编号、状态全部正确
- 通知到位：提报人收到通过/退回消息
