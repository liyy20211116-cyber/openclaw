_2026-04-10 02:00_ 【重要项目】ONES 需求审核自动化

## 项目背景
公司（稳健集团）使用飞书多维表格收集业务需求和 BUG，需要人工逐条审核后手动在 ONES 系统创建工作项。CEO 要求将此流程全自动化。

## 当前架构
飞书多维表格（数字化需求&BUG收集池）→ 审核卡片推送到 CEO 飞书 → CEO 点击通过/退回 → 自动在 ONES 创建工作项 → 回写飞书表格链接+编号 → 通知提报人

## 已完成模块
1. **配置完备**：所有 ONES UUID（工作项类型、字段、产品、优先级、严重程度）已通过 API 探测并填写完毕（2026-03-13）
2. **飞书扫描**：scan_and_send.py 能扫描"待审批"状态的记录并发送审核卡片
3. **卡片回调**：card_action_handler.py（WebSocket 长连接）能处理通过/退回/跳过操作
4. **ONES 自动建单**：create_ones_task_ui.py 通过 Playwright 操控 ONES 页面弹窗创建工作项（因 API 有 IssueTypeScope 作用域限制，改为 UI 自动化）
5. **Token 自动刷新**：ones_token_refresh.py 通过 WIS SSO 全自动获取 ONES Bearer Token（约 40 秒，有效期 1 小时）
6. **飞书回写**：通过/退回后自动更新飞书表格状态、链接、编号、审批时间
