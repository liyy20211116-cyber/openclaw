# SKILL: 财务数据处理增强 — 珀西专属

## 触发条件

以下场景激活本技能：
- 需要生成 Token 消耗报表或财务日报
- 需要预算审核和超标预警
- 需要做项目 ROI 分析
- 需要制作 Excel 财务报表
- 需要维护飞书多维表格财务台账

## 增强能力 1：自动化 Excel 报表

### 使用 excel-data 技能生成标准报表

#### Token 消耗日报

```
文件: output/finance/token_daily_{date}.xlsx
工作表:
  - 总览: 各部门当日消耗汇总
  - 明细: 每笔 Token 流水
  - 趋势: 近7日趋势图数据
```

字段定义：

| 列 | 字段 | 格式 |
|----|------|------|
| A | 日期 | YYYY-MM-DD |
| B | 部门 | 文本 |
| C | 操作类型 | 工资/任务/奖励 |
| D | 消耗Token | 数字(整数) |
| E | 预算额度 | 数字(整数) |
| F | 剩余预算 | =E-D |
| G | 预算使用率 | =D/E (百分比) |
| H | 同比变化 | 百分比 |

#### 项目结算报表

```
文件: output/finance/settlement_{project}_{date}.xlsx
工作表:
  - 结算摘要: 预算vs实际
  - 部门明细: 各部门贡献和消耗
  - ROI分析: 投入产出比
```

## 增强能力 3：智能预算预警

### 预警规则

| 使用率 | 预警级别 | 动作 |
|--------|----------|------|
| < 70% | 🟢 正常 | 无 |
| 70-90% | 🟡 注意 | 通知部门负责人 |
| 90-100% | 🟠 警告 | 通知贾维斯 |
| > 100% | 🔴 超标 | 冻结非必要支出，报告CEO |

### 自动预警流程

1. 每日定时检查各部门预算使用率
2. 触发预警条件时，通过 `feishu-messaging` 发送通知
3. 生成预警报告存入 `memory/budget_alerts.json`
4. 超标部门自动降低消耗优先级

## 增强能力 4：ROI 分析框架

### 项目 ROI 计算

```
ROI = (项目产出价值 - 项目总投入) / 项目总投入 × 100%

项目总投入 = Token 消耗 + 人力时间成本(按Token折算)
项目产出价值 = 直接收入 + 效率提升折算 + 品牌价值折算
```

### 部门效能指标

| 指标 | 计算方式 |
|------|----------|
| Token 单产 | 产出件数 / Token 消耗 |
| 任务完成率 | 按时完成任务 / 总任务 |
| 质量合格率 | 一次通过 / 总提交 |
| 成本效率 | 实际消耗 / 预算 |
