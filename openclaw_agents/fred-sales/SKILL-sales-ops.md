# SKILL: 销售商务增强 — 弗雷德专属

## 触发条件

以下场景激活本技能：
- 需要调研潜在客户背景信息
- 需要制定报价方案和商务策略
- 需要管理销售漏斗和客户数据
- 需要生成商务文档（合同、方案、报价单）
- 需要收集竞品定价和市场情报

## 增强能力 1：客户智能调研

### 使用 web-search + browser-automation

调研流程：
1. **公司搜索** — WebSearch 搜索客户公司名称、行业、规模
2. **官网分析** — WebFetch 获取客户官网关键页面
3. **深度调研** — browser-use 截取客户产品页面、团队页面
4. **信息整理** — 输出客户画像卡片

### 客户画像卡片模板

```markdown
## 客户画像 — {公司名}

### 基本信息
- 公司全称：
- 行业：
- 规模：{员工数/营收}
- 官网：
- 所在地：

### 业务分析
- 核心产品/服务：
- 目标客户群：
- 近期动态：{融资/新品/扩张}

### 需求预判
- 可能的痛点：
- 我们可提供的价值：
- 决策链：{谁做采购决策}

### 商务策略
- 破冰方式：
- 推荐方案：
- 预期报价范围：
- 成交概率：{%}
```

## 增强能力 2：智能报价系统

### 报价策略矩阵

| 客户类型 | 定价策略 | 折扣上限 | 审批级别 |
|----------|----------|----------|----------|
| 标杆客户 | 成本价+品牌溢价 | 30% | CEO |
| 大客户 | 阶梯定价 | 20% | 贾维斯 |
| 中小客户 | 标准定价 | 10% | 弗雷德 |
| 试用客户 | 免费/极低价 | 100% | 贾维斯 |

### 报价单生成

使用 `excel-data` 技能生成 Excel 报价单：

| 列 | 内容 |
|----|------|
| 服务项目 | 产品/服务名称 |
| 规格说明 | 具体包含内容 |
| 单价 | 标准单价 |
| 数量 | 购买数量 |
| 折扣 | 折扣比例 |
| 小计 | 计算后金额 |

使用 `libreoffice-safe-export` 导出为 PDF 发送。

## 增强能力 3：CRM 数据管理

### 飞书多维表格 CRM

使用 `feishu-workflow-bitable` 技能管理客户数据：

**客户主表字段**：
- 客户名称、联系人、联系方式
- 客户来源、行业、规模
- 当前阶段、成交概率
- 预期金额、预计成交日
- 上次跟进时间、下次跟进计划
- 负责人、备注

**跟进记录表**：
- 日期、客户、跟进方式
- 沟通内容、客户反馈
- 下一步行动、截止时间

### 销售漏斗自动化

```
线索(Lead) → 初步沟通(Contact) → 方案报价(Proposal) → 谈判(Negotiate) → 成交(Won)/丢失(Lost)
```

每阶段自动：
1. 更新多维表格状态
2. 通知相关人员
3. 触发下一步动作模板

## 增强能力 4：商务文档工厂

| 文档类型 | 生成方式 | 输出格式 |
|----------|----------|----------|
| 公司介绍 | LLM + 模板 | Markdown → PDF |
| 方案提案 | LLM + 数据 | Markdown → PDF |
| 报价单 | Excel 模板 | Excel → PDF |
| 合作协议 | 模板填充 | Word → PDF |
| 案例分析 | LLM + 调研 | Markdown |

### 文档生成流程

1. 选择模板类型
2. 填入客户信息和方案参数
3. LLM 生成文案内容
4. 格式化输出（Markdown/Excel）
5. 导出 PDF（使用 libreoffice-safe-export）
6. 提交贾维斯审批后发送

## 增强能力 5：市场竞品情报

定期（每周）执行：
1. WebSearch 搜索竞品最新动态
2. 竞品价格变动监控
3. 竞品新功能/新产品跟踪
4. 整理竞品情报周报

## 增强能力：销售管线管理

```powershell
python -u D:\FY003\scripts\sales_pipeline.py
```

管理客户线索全生命周期：线索→初步接触→需求确认→方案演示→报价→谈判→成交/流失。
自动生成销售漏斗统计和关键 KPI（管线价值、转化率、成交额）。

数据文件：`data_raw/sales_pipeline.json`（可手动编辑添加线索）
输出：`output/sales_report_{date}.json`
