# SKILL: 客户成功增强 — 多比专属

## 触发条件

以下场景激活本技能：
- 需要从用户视角测试产品体验
- 需要收集和整理客户反馈
- 需要维护客户帮助文档和 FAQ
- 需要做满意度调查和分析
- 需要跟进客户问题直到解决

## 增强能力 1：浏览器 UX 自动化测试

### 使用 browser-automation 做体验走查

核心场景测试清单：

| 场景 | 测试内容 | 验证点 |
|------|----------|--------|
| 新手引导 | 首次使用流程 | 步骤是否清晰、无卡点 |
| 核心流程 | 主要功能路径 | 功能完整、响应及时 |
| 异常处理 | 错误输入/网络断开 | 提示友好、不崩溃 |
| 通知体验 | 飞书通知/卡片 | 内容清晰、链接可用 |
| 移动端 | 不同屏幕尺寸 | 布局正常、可交互 |

### 走查流程

1. 启动 `browser-use` 子代理
2. 按照测试场景逐步操作
3. 每个关键步骤截图
4. 记录发现的问题
5. 输出体验走查报告

### 走查报告模板

```markdown
## UX 走查报告 — {功能/流程名}

**走查日期**：{date}
**走查人**：多比
**总体评分**：{1-10}/10

### 走查路径
1. {步骤1} — ✅/⚠️/❌ {备注}
2. {步骤2} — ✅/⚠️/❌ {备注}
3. ...

### 发现问题

| # | 问题 | 严重度 | 截图 | 建议 |
|---|------|--------|------|------|
| 1 | {描述} | 高/中/低 | {截图路径} | {建议} |

### 亮点
- {体验好的地方}

### 改进建议
- {优先级排序的建议清单}
```

## 增强能力 2：客户反馈管理

### 反馈收集渠道

| 渠道 | 采集方式 | 工具 |
|------|----------|------|
| 飞书群消息 | 定期扫描客户群历史消息 | `im_v1_message_list` |
| 多维表格 | 客户提交的反馈表 | `feishu-workflow-bitable` |
| 邮件 | 客户邮件反馈 | 手动录入 |
| 产品内反馈 | 应用内反馈入口 | API 获取 |

### 反馈分类体系

| 类别 | 说明 | 对接部门 |
|------|------|----------|
| Bug | 功能故障、显示异常 | 赫敏（技术） |
| 功能建议 | 新功能需求 | 麦格教授（产品） |
| 体验优化 | 使用不便、流程复杂 | 麦格教授（产品） |
| 文档缺失 | 帮助文档不清楚 | 多比（自己） |
| 商务问题 | 定价、合作、付款 | 弗雷德（销售） |

### 反馈处理流程

```
收到反馈 → 分类归档 → 优先级评估 → 分派对口部门
    → 跟进处理进度 → 确认解决 → 通知客户 → 满意度回访
```

## 增强能力 4：满意度监控

### 满意度指标

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| CSAT | 满意评分均值 | ≥ 4.0/5.0 |
| NPS | 推荐者%-贬损者% | ≥ 30 |
| 首次响应时间 | 从问题提交到首次回复 | ≤ 4小时 |
| 解决时间 | 从问题提交到确认解决 | ≤ 48小时 |
| 解决率 | 已解决/总问题 | ≥ 90% |

### 使用 excel-data 制作满意度报表

```
文件: output/feedback/satisfaction_{month}.xlsx
工作表:
  - 月度概览: CSAT、NPS、响应时间等汇总
  - 问题明细: 所有客户问题和处理记录
  - 趋势分析: 各指标月度变化趋势
```

## 增强能力 5：主动关怀

### 关怀触发条件

| 条件 | 动作 |
|------|------|
| 新客户开通 | 发送欢迎消息+入门指引 |
| 7天未登录 | 发送关怀消息+使用提示 |
| 提交严重问题 | 升级处理+主动回访 |
| 使用里程碑 | 发送祝贺+进阶指引 |
| 反馈被采纳 | 通知客户改进已上线 |
