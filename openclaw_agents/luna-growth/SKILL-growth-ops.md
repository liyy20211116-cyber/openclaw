# SKILL: 增长运营增强 — 卢娜专属

## 触发条件

以下场景激活本技能：
- 需要追踪热点话题和趋势
- 需要生成多平台内容（公众号/短视频/博客/社媒）
- 需要 SEO 关键词研究和优化
- 需要制作视觉素材（配图/封面/缩略图）
- 需要分析内容效果和优化策略

## 增强能力 1：热点追踪与选题

### 信息源

| 转化潜力 | 20% | 对获客/品牌的潜在贡献 |

## 增强能力 2：多平台内容生产

### 内容适配矩阵

| 平台 | 格式 | 长度 | 风格 |
|------|------|------|------|
| 公众号 | 长文 | 2000-5000字 | 深度、专业 |
| 短视频 | 脚本+视频 | 60-180秒 | 节奏快、有料 |
| 博客/SEO | 文章 | 1000-3000字 | 教程式、结构化 |
| 社交媒体 | 帖文 | 100-500字 | 轻松、有互动性 |
| 邮件 | Newsletter | 500-1000字 | 精炼、有CTA |

### 内容生产流程

1. **选题确认** — 与弗雷德对齐获客目标
2. **大纲撰写** — 结构化提纲
3. **正文创作** — 使用 LLM 辅助，人工把关调性
4. **素材制作** — 使用 `image-gen` 生成配图
5. **视频渲染** — 使用 `content-pipeline` 全自动出片
6. **审核** — 提交贾维斯审批
7. **发布** — 多平台分发
8. **数据追踪** — 一周后复盘

## 增强能力 4：SEO 和搜索优化

### 关键词研究流程

1. 使用 `web-search` 搜索 "{主题} 关键词" 获取灵感
2. 分析搜索意图（信息型/导航型/交易型）
3. 评估竞争度和搜索量
4. 选择长尾关键词作为切入点

### 内容 SEO 检查清单

- [ ] 标题包含核心关键词
- [ ] 副标题使用 H2/H3 结构
- [ ] 首段100字内出现关键词
- [ ] 内链和外链合理
- [ ] Meta 描述优化
- [ ] 图片 Alt 文本设置

## 增强能力：内容素材自动生成

```powershell
python -u D:\FY003\scripts\growth_content_gen.py
```

基于 `data_raw/news_*.json` 中的新闻数据，自动生成：
- 每日行业日报草稿（5条精选）
- 深度解读选题（1条深度分析）
- 社交媒体帖子草稿（3条短内容）
- 一周内容排期建议

输出 `output/content_drafts_{date}.json`，由卢娜审核编辑后发布。

前置步骤：先运行 `python -u D:\FY003\scripts\fetch_news.py` 抓取最新新闻。
