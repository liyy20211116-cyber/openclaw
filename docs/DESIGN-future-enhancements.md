## 2. 增强方向

### 方向一：定时自动化（优先级：高）

**目标**：让公司不需要CEO手动触发就能自动运行

#### 设计

使用 OpenClaw 的 `cron` 系统设置定时任务：

| 任务 | 频率 | 脚本 | 产出 |
|:---|:---|:---|:---|
| 每日运营报告 | 每天 09:00 | `company_daily_report.py` | 飞书推送日报 |
| 新闻抓取 | 每天 08:00 | `fetch_news.py` + `rank_news.py` | 新闻数据更新 |
| 安全扫描 | 每天 22:00 | `audit_security_scan.py` | 安全报告 |
| 记忆整理 | 每周日 20:00 | `agent_learn.py --all` | 压缩版记忆 |
| 周反思 | 每周一 09:00 | `weekly_reflection.py` | 周报 |
| 竞品扫描 | 每周三 10:00 | `product_competitive_scan.py` | 竞品报告 |
| 依赖安全检查 | 每月1号 | `dependency_security_check.py` | 安全报告 |

#### 实现方式

修改 `~/.openclaw/cron/jobs.json`，新增任务条目，delivery 设为飞书推送。

#### 安全考量
- 定时任务只做只读分析和报告，不执行写操作
- 安全扫描结果不推送到群聊，只发给 CEO 个人

---

### 方向二：飞书报告推送（优先级：高）

**目标**：各部门报告自动推送到飞书

#### 设计

```
脚本执行 → 生成报告 → 格式化为飞书消息卡片 → 推送到指定群/个人
```

新增脚本 `feishu_report_push.py`：
- 读取 `output/` 目录下最新报告
- 转换为飞书富文本/卡片格式
- 通过飞书 API 推送

#### 推送规则

| 报告类型 | 推送给 | 格式 |
|:---|:---|:---|
| 每日运营报告 | CEO 个人 | 富文本消息 |
| 安全告警（HIGH+） | CEO 个人 | 紧急卡片 |
| 周反思 | CEO 个人 | 飞书文档 |
| 竞品报告 | CEO 个人 | 表格消息 |

---

### 方向三：Web 仪表板前端（优先级：中）

**目标**：jarvis-one-company-os 接入实时数据

#### 设计

在现有 Electron 前端中增加数据展示页面：
- 读取 `output/` 目录下的 JSON 报告
- 展示项目健康度仪表盘
- 展示各部门最新状态
- 展示销售漏斗和财务概览

#### 技术方案
- 前端：Vue/React + Chart.js
- 数据源：直接读取本地 `output/*.json`
- 无需后端API，Electron 本地文件读取

---

### 方向四：客户CRM飞书同步（优先级：中）

**目标**：销售管线数据与飞书多维表格双向同步

#### 设计

```
本地 sales_pipeline.json ←→ 飞书多维表格（CRM）
```

新增脚本 `crm_feishu_sync.py`：
- 读取本地管线数据
- 同步到飞书多维表格
- 从飞书拉取新增线索写回本地
- 冲突解决：飞书优先（人工编辑权重高于自动）

---

### 方向五：多语言内容（优先级：低）

**目标**：增长部能生成中英双语内容

#### 设计
- 利用 LLM 翻译中文内容为英文
- 新增英文 SEO 关键词库
- 在 `growth_content_gen.py` 中增加 `--lang en` 参数

---

### 方向六：语音交互（优先级：低）

**目标**：CEO 可以语音下达指令

#### 设计
- 集成 Whisper / Azure Speech 做语音转文字
- 转换后的文字直接发送给贾维斯处理
- 适用于移动端场景
