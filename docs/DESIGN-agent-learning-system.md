## 版本
- v1.0 | 2026-04-11
- 作者：Cursor AI (代 CEO 起草)
- 状态：待 CEO 审批

---

## 1. 目标

让一人公司每个 Agent 都具备自我学习能力，在各自业务领域越用越强。同时确保贾维斯（COO）对所有 Agent 记忆的管辖权——他可以查看、审计、压缩任何 Agent 的记忆。

### 核心原则

1. **各司其职** — 每个 Agent 只在自己的业务领域积累记忆
2. **COO 统管** — 贾维斯可以读取、审计、压缩任何 Agent 的记忆
3. **记忆分级** — 按重要性分为日常/重要/关键三级
4. **安全可控** — 敏感信息不写入记忆，审计部可审查所有记忆内容

## 2. 架构设计

### 2.1 记忆层级

```
贾维斯（COO）
├── 自有记忆（公司级决策、CEO偏好、组织管理）
├── 全局知识库（公司制度、文化、OKR）
└── 管辖所有 Agent 记忆
    ├── 赫敏 → 技术经验、架构决策、Bug修复记录
    ├── 麦格 → 产品洞察、竞品变化、用户需求
    ├── 卢娜 → 内容效果、增长实验、热点趋势
    ├── 弗雷德 → 客户画像、销售话术、成交模式
    ├── 珀西 → 成本规律、预算执行、财务指标
    ├── 斯内普 → 安全漏洞库、审计发现、风险模式
    └── 多比 → 客户问题库、满意度趋势、FAQ更新
```

### 2.2 每个 Agent 的记忆目录结构

```
openclaw_agents/{agent}/memory/
├── learnings.md          # 长期学习记录（核心文件）
├── learnings_compressed.md  # 压缩版（由整理脚本生成）
├── domain_knowledge.json  # 领域知识库（结构化数据）
└── reflection_log.json    # 反思日志（周反思结果）
```

### 2.3 记忆写入规范（统一格式）

```markdown
---
_{日期 时间}_ 【{分类}】{一句话结论}

{补充细节，不超过3行}（可选）
```

**分类标签**（各 Agent 按领域自定义）：

| Agent | 分类标签 |
|:---|:---|
| 赫敏 | `架构决策`、`Bug修复`、`技术方案`、`工具经验`、`代码规范` |
| 麦格 | `需求洞察`、`竞品变化`、`用户行为`、`产品决策`、`市场趋势` |
| 卢娜 | `内容效果`、`增长实验`、`热点趋势`、`渠道数据`、`创意灵感` |
| 弗雷德 | `客户画像`、`销售话术`、`成交模式`、`报价经验`、`流失原因` |
| 珀西 | `成本规律`、`预算异常`、`ROI分析`、`定价策略`、`财务风险` |
| 斯内普 | `安全漏洞`、`审计发现`、`风险模式`、`合规要求`、`攻防经验` |
| 多比 | `常见问题`、`满意度`、`功能请求`、`服务改进`、`知识更新` |

### 2.4 记忆权限模型

| 操作 | Agent本人 | 贾维斯(COO) | 斯内普(审计) | 其他Agent |
|:---|:---:|:---:|:---:|:---:|
| 写入自己记忆 | ✓ | ✓ | ✗ | ✗ |
| 读取自己记忆 | ✓ | ✓ | ✓ | ✗ |
| 压缩自己记忆 | ✓ | ✓ | ✗ | ✗ |
| 读取他人记忆 | ✗ | ✓ | ✓(只读) | ✗ |
| 删除记忆 | ✗ | ✓(审批) | ✗ | ✗ |

## 3. 工具设计

### 3.1 各 Agent 通用学习脚本

**`agent_learn.py`** — 放在 `scripts/` 目录，所有 Agent 共用

功能：
1. 读取指定 Agent 的 `learnings.md`
2. 去重（基于前80字符）
3. 按该 Agent 的分类标签分类
4. 生成 `learnings_compressed.md`
5. 生成 `domain_knowledge.json`（结构化知识库）
6. 输出整理报告

调用方式：
```powershell
python -u D:\FY003\scripts\agent_learn.py --agent hermione-tech
python -u D:\FY003\scripts\agent_learn.py --agent snape-audit
python -u D:\FY003\scripts\agent_learn.py --all  # 整理所有Agent
```

### 3.2 COO 全局记忆审计

**`coo_memory_audit.py`** — 贾维斯专用

功能：
1. 扫描所有 Agent 的记忆文件
2. 统计各 Agent 记忆量和最后更新时间
3. 检查是否有记忆断层（超过3天未更新）
4. 检查是否有敏感信息泄露到记忆中
5. 生成全公司记忆健康报告

### 3.3 学习触发规则

每个 Agent 应在以下时机写入记忆：

| 触发条件 | 写什么 |
|:---|:---|
| 完成一项任务 | 经验总结（成功/失败原因） |
| 遇到新问题 | 问题描述和解决方案 |
| CEO 做出决策 | 决策内容和背景 |
| 发现新工具/方法 | 工具评价和使用方法 |
| 犯了错误 | 错误原因和避免方法 |

## 5. 安全考量

1. **敏感信息过滤** — 记忆写入时自动过滤密码、Token、API Key
2. **记忆审计** — 斯内普可随时审查任何 Agent 的记忆
3. **权限隔离** — Agent 不能读取其他 Agent 的记忆
4. **备份机制** — 记忆文件纳入 Git 版本控制

---

## 6. 风险评估

| 风险 | 等级 | 缓解措施 |
|:---|:---:|:---|
| Agent 写入低质量/重复记忆 | 中 | 定期压缩去重 |
| 敏感信息泄露到记忆 | 高 | 写入时过滤 + 审计扫描 |
| 记忆文件过大影响性能 | 低 | 压缩后控制在 100 条以内 |
| Agent 记忆互相冲突 | 低 | 权限隔离 + COO 仲裁 |
