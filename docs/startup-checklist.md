## 四、获客触达通道 — 让Fred自动联系客户

### 邮件通道

| 步骤 | 你需要提供 |
|------|-----------|
| 1 | 🔑 选择邮箱：推荐QQ邮箱或网易企业邮 |
| 2 | 🔑 登录邮箱 → 设置 → 开启SMTP/IMAP服务 |
| 3 | 🔑 获取SMTP授权码（注意：不是邮箱登录密码！） |
| 4 | 填入 `config/integrations.json` → `outreach.email` |
| 5 | 设置 `email.enabled` 为 `true` |

**常用SMTP配置**：
- QQ邮箱：`smtp.qq.com` 端口 `465`
- 网易企业邮：`smtp.qiye.163.com` 端口 `465`
- 163邮箱：`smtp.163.com` 端口 `465`

## 启动流程

```
1. 填写 config/integrations.json（至少填LLM Key）
2. 启动桌面端 → 系统自动加载17个定时任务
3. 首次启动会补跑错过的任务
4. 系统开始自动运行：
   - 每天9点：IP打造流水线 + 运营巡检
   - 每天10点：销售线索评估（周一三五）
   - 每天14点：内容管道（周二四）
   - 每天18点：CEO日报
   - 全天：异常检测（每30分钟）
5. 你只需要：
   - 早上花5分钟看日报 + 审核内容
   - 有新线索时花10分钟决策跟进策略
   - 其余时间，系统自主运行
```
