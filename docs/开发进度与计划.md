## 一、项目主链路（不可偏离）

```
CEO 下达目标 → 贾维斯拆解任务 → 多角色协同执行 → Token 预算流转 → 审核与复盘 → 产出可售卖结果
```

MVP 成功标准（来自设计文档）：
1. CEO 能发出一个目标
2. 贾维斯能拆解成任务
3. 至少 3 个角色能协同完成一次业务流程
4. 财务官能记录 Token 收支
5. 审计官能拦截至少一种风险行为
6. 系统能形成一个简单盈利案例

### 阶段 B：数据闭环打通（预计 2-3 天）

> 目标：让所有页面之间的数据流真正串联，形成完整的业务闭环

#### B-1. 打通「任务→审批→执行→流水」全链路 ⏱ 1 天
- 创建任务时自动生成审批请求（如 requires_approval = true）
- 审批通过后自动变更任务状态为 approved
- 任务执行完成后自动生成 Token 扣减流水
- 任务完成后可触发 KPI 更新
- 确保每个操作都写入 task_logs

#### B-2. 打通「收入→分账→国库」闭环 ⏱ 0.5 天
- 新增收入时自动触发内部 Token 分账
- 按预设权重分配到相关角色钱包
- 国库沉淀剩余部分
- 更新财务流水

#### B-3. 打通「审计→冻结→复核」闭环 ⏱ 0.5 天
- 审计事件可触发任务冻结
- 冻结后需要 CEO/贾维斯审批才能恢复
- 记录审计事件到任务日志

#### B-4. 驾驶舱数据精准化 ⏱ 0.5 天
- 修复 `weeklyRevenue` 为真正的本周数据
- 补充「今日 Token 支出」精确计算
- 补充「风险事件数」实时聚合
- 快捷操作按钮全部可用（创建任务/发工资/新增收入/打开超市）

#### B-5. 角色详情增强 ⏱ 0.5 天
- 点击角色卡片打开详情抽屉/侧面板
- 展示：人格设定、目标列表、权限列表、最近任务、最近消费流水、最近奖励

### 阶段 E：OpenClaw 集成 ✅ 已完成

#### E-1. 角色-Agent 映射设计 ✅
- `config/openclaw-agents.json`：6 角色到 OpenClaw agentId 的映射配置
- `config/openclaw-workspaces/`：为 5 个执行角色创建 IDENTITY.md
  - `jarvis-coordinator`（贾维斯）：目标拆解 + 任务协调

  - `jarvis-growth`（增长官）：内容/获客/转化
  - `jarvis-finance`（财务官）：预算/账本/报表
  - `jarvis-audit`（审计官）：巡检/合规/冻结

#### E-2. 任务执行引擎 ✅
- `scripts/execute-task-openclaw.ts`：完整的 OpenClaw 调用链
  - 读取任务 → 查找 Agent 映射 → 构建 Prompt → `sessions_spawn` → 轮询状态 → 结果回写
  - 支持 `dryRun` 模式预览 Prompt
  - 自动处理任务状态流转（approved → in_progress → review）
  - 错误容错：OpenClaw 未启动时优雅降级
- 前端：任务详情面板增加「OpenClaw 自动执行」按钮
- `writeback-api.ts`：新增 `/api/writeback/execute-task-openclaw` 端点

#### E-3. 审计官自动巡检 ✅
- `scripts/audit-inspection.ts`：4 类自动检查

  - 超期检查（1/3/7 天分级）
  - 描述完整性检查（<10 字标记）
  - 重复任务检查（同负责人标题相似）
- 自动生成审计事件，高风险自动扣减合规分
- 幂等设计：已有相同类型 open 事件不重复创建
- 前端：审计中心增加「自动巡检」按钮
- `writeback-api.ts`：新增 `/api/writeback/audit-inspection` 端点

## 十一、关键原则提醒

1. **先做制度与系统，再做能力与规模** — 不要急着接 OpenClaw，先把「公司制度界面」做出来
2. **按模块推进** — 每次只实现一个清晰、可运行、可验收的功能块
3. **主链路优先** — 所有开发都围绕「目标→任务→执行→收益→复投」这条主链路
4. **Token 只做内部账本** — 第一阶段不做链上资产、不做提现
5. **角色不超过 6 个** — 控制复杂度
6. **所有执行都应可审计** — 保留完整操作日志
7. **LLM 调用必须有 fallback** — 规则引擎始终保留作为降级方案
8. **打包必须开箱即用** — 用户双击即可启动，不需要额外配置
