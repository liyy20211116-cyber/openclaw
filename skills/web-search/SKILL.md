# Web Search — 网络搜索与信息获取

所有角色共享的互联网信息获取能力。

## 适用场景

- 查询实时新闻、行业趋势、竞品信息
- 搜索技术文档、API 参考、开源项目
- 获取市场数据、价格信息、政策法规
- 验证信息准确性、事实核查
- 查找最佳实践、解决方案参考

## 可用工具

| 工具 | 用途 | 备注 |
|------|------|------|
| `WebSearch` | 关键词搜索，返回摘要和链接 | 适合快速了解概况 |
| `WebFetch` | 抓取指定 URL 内容，返回 Markdown | 适合深入阅读特定页面 |

## 使用流程

### 1. 快速搜索

先用 WebSearch 获取概览：
- 关键词要具体，包含年份/版本号可提高时效性
- 技术搜索加上框架名+版本号
- 中文搜索和英文搜索各有优势，可交替使用

### 2. 深入获取

对搜索结果中的重要链接，用 WebFetch 获取完整内容：
- 官方文档优先
- 注意页面可能需要认证（WebFetch 不支持认证页面）
- 获取后提取关键信息，不要全文转发

### 3. 信息整合

- 多源交叉验证，不依赖单一来源
- 标注信息来源和时间
- 区分事实和观点

## 注意事项

- 搜索查询今年用 2026 年
- 不在搜索中暴露公司内部敏感信息
- 优先使用官方/权威来源
- 搜索结果可能过时，注意检查发布日期
