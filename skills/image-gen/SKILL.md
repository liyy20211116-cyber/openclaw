# Image Gen — AI 图片生成

所有角色共享的图像生成能力。

## 适用场景

- 生成文章配图、封面图
- 创建产品原型示意图
- 制作信息图和数据可视化插图
- 生成社交媒体配图
- 创建图标、Logo 草图
- 制作演示文稿插图

## 可用工具

| 工具 | 用途 | 备注 |
|------|------|------|
| `GenerateImage` | AI 文本转图像 | Cursor 内置，直接可用 |
| OpenAI Image API | 高级图像生成/编辑 | 需要 OPENAI_API_KEY |

## 使用 GenerateImage

直接通过工具调用：

- `description`: 详细描述图片内容、风格、颜色、布局
- `filename`: 可选，指定文件名
- `reference_image_paths`: 可选，参考图片路径

### 描述写法指南

好的描述包含：
1. **主体** — 图片中有什么
2. **风格** — 扁平化/写实/手绘/极简
3. **颜色** — 主色调和配色
4. **布局** — 构图和空间安排
5. **文字** — 如需要包含文字（尽量少）

示例：
- "扁平化矢量风格的团队协作插画，5个人围坐在圆桌旁讨论，蓝色和橙色配色，白色背景，现代商务风"
- "深色背景的科技感数据仪表盘示意图，包含3个折线图和2个饼图，蓝紫色渐变主色调"

## 图片管理

- 生成的图片保存到 `output/images/` 目录
- 文件名格式：`{用途}_{日期}_{序号}.png`
- 保留生成时的 description 用于后续复现
- 定期清理不需要的临时图片

## 注意事项

- 图片描述要用英文效果更好，中文也支持
- 不生成包含真实人物肖像的图片
- 不生成包含敏感/争议内容的图片
- 信息图/数据图建议用代码（matplotlib/echarts）而非 AI 生成
- 需要精确文字的场景，AI 生成不够可靠，后期用工具叠加
