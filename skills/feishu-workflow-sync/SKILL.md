# Feishu Workflow Sync

这个 Skill 用于把一份工作流内容同时落到：

- 飞书云文档 / 知识库页面
- 飞书多维表格任务板

## 适用场景

- 帮我整理流程说明，同时拆成执行清单
- 帮我出一份 SOP，并同步到任务台账
- 帮我写文档，再把步骤录入多维表格
- 帮我做一套可执行的项目流程页面

## 推荐策略

### 文档层负责

- 背景
- 目标
- 完整流程说明
- 风险 / 注意事项
- 责任说明

### 多维表格层负责

- 任务项
- 负责人
- 状态
- 优先级
- 时间节点

## 执行步骤

1. 先整理用户原始需求，产出结构化流程
2. 用 `feishu_doc` 或 `feishu_wiki + feishu_doc` 落正文
3. 用 `feishu_bitable_*` 工具落执行项
4. 如果合适，在文档中补充“任务板链接/表格引用说明”

## 拆解建议

若用户没有明确要求字段，可默认拆成：

- 步骤名称
- 负责人
- 输入
- 输出
- 状态
- 截止时间

## 工作原则

- 文档和表格职责分离，不要把大段说明直接写进 bitable
- 优先保证文档成型，再同步执行项
- 如果用户只要文档，不要强行创建 bitable
- 如果用户只要任务板，也不要额外制造文档

## 对外回复

至少告诉用户：

- 文档是否已创建/更新
- 多维表格是否已同步
- 当前落地结果包含哪些内容
