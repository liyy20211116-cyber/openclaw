各位同学好，培训材料请按下面步骤操作：

1. 下载压缩包 `OpenClaw培训包_学员版.zip`
2. 解压到 `D:\FY003`
3. 不要修改文件名和目录名
4. 直接双击 `一键启动.bat`
5. 如果提示缺少 Node.js，请先安装 Node.js 22 或更高版本
6. 启动成功后，浏览器访问 `http://127.0.0.1:18789/`
7. 后续按照培训课件继续完成“模型接入”和“飞书配对”

补充说明：
- `一键启动.bat` 本质上会调用 `openclaw_安装并启动.ps1` 完成安装与启动
- 不需要自己新建 `.ps1` 文件
- 不需要自己修改脚本内容
- 如果网络受限，可能会影响 npm 安装，请提前确认网络可用

课前建议先检查：
- Windows 10 / 11
- PowerShell 可用
- Node.js 版本 >= 22
- 可以访问 npm 和飞书开放平台
