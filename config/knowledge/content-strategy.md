# 内容策略框架

## 一、内容定位模型

### 黄金三角
```
    市场需求（搜索量/讨论量）
       /          \
      /            \
个人优势 ———— 竞争空白
（你擅长的）  （别人没做好的）
```

三者交集 = 你的内容定位

### 定位公式
**「我帮 [目标用户] 解决 [核心痛点]，通过 [独特方式]」**

## 二、选题方法论

### 选题四象限
| | 高搜索量 | 低搜索量 |
|---|---------|---------|
| **低竞争** | **蓝海爆款**（优先做） | 长尾精准 |
| **高竞争** | 红海血战（有实力再做） | 避开 |

### 选题来源
1. **平台搜索框**：输入关键词看下拉推荐
2. **竞品分析**：爆款笔记的主题和角度
3. **评论区**：用户问的最多的问题
4. **热榜/话题**：平台推荐的热门话题
5. **行业报告**：数据驱动的趋势洞察

### 选题评估标准
| 维度 | 评分标准（1-5分） |
|------|------------------|
| 用户痛点强度 | 刚需(5) → 可有可无(1) |
| 搜索需求量 | 高频搜索(5) → 无人搜(1) |
| 竞争密度 | 几乎没人做(5) → 红海(1) |
| 变现潜力 | 直接转化(5) → 纯流量(1) |
| 制作难度 | 1小时搞定(5) → 需要1周(1) |

总分 > 18 分：立即做
总分 13-17 分：排队做
总分 < 12 分：暂时放弃

## 三、内容生产流程

### 标准化流程
```
选题 → 竞品调研 → 大纲 → 素材准备 → 制作 → 审核 → 发布 → 数据追踪
 2h      1h       30m     2h        2h     30m    10m     持续
```

### 内容复用矩阵
一个核心内容 → 多平台分发：

| 原始格式 | 可衍生为 |
|---------|---------|
| 长文章 | 小红书图文 → 公众号文章 → 知乎回答 |
| 长视频 | 抖音短视频 → B站中视频 → 视频号 |
| 直播 | 直播切片 → 短视频 → 图文总结 |
| 播客 | 文字版 → 金句图 → 短视频片段 |

## 四、数据分析框架

### 核心指标
| 指标 | 说明 | 达标线 |
|------|------|--------|
| 曝光量 | 被推荐展示次数 | 增长趋势 |
| 点击率 | 曝光→点击 | > 5% |
| 完播率 | 开始→看完 | > 30% |
| 互动率 | 点赞+评论+收藏/曝光 | > 5% |
| 转粉率 | 观看→关注 | > 2% |
| 收藏率 | 收藏/曝光 | > 3% |

### 数据复盘模板
```
## 周数据复盘 — 第 N 周

### 本周数据概览
- 发布内容：X 条
- 总曝光：X
- 总互动：X
- 新增粉丝：X
- 收入：X 元

### 爆款分析
- 最高曝光内容：[标题]，分析原因
- 最高互动内容：[标题]，分析原因

### 低效内容分析
- 最低数据内容：[标题]，分析原因

### 下周调整
- 多做：xxx 类型的内容
- 少做：xxx 类型的内容
- 测试：xxx 新方向
```

## 五、增长飞轮

```
优质内容 → 获得推荐 → 吸引关注 → 粉丝互动
    ↑                                    |
    |                                    ↓
反馈优化 ← 数据分析 ← 内容持续 ← 提高权重
```

核心：**每个环节的效率提升都会加速整个飞轮**
