# Jarvis 一人公司对标经营 Playbook

## 核心判断

Jarvis 现阶段不要急着卖 OS。先用 OS 自己运营出一个小结果，再把结果产品化。

主线：

1. 自营赚钱。
2. 记录过程。
3. 公开证据。
4. 沉淀 Skill。
5. 再销售系统。

## 内容钩子库

- 一个人就是一支运营团队。
- 一人公司收入全公开。
- 从 0 到第一单，第 N 天。
- AI Agent 工具观察：谁值得学，谁只是热闹。
- 5 个自动运行的小龙虾/数字员工。
- 3 个让一人公司效率翻倍的 Skill。
- 只听不说的微信私域雷达。

## 商业模式

### 自营服务优先

- 99 元 AI 工作流诊断。
- 999 元启航版经营循环搭建。
- 2999 元标准版私域/内容/销售闭环搭建。
- 399 元/月运营陪跑。

### Skill 单品

- 微信摘要雷达。
- 销售线索评分器。
- 报价/付款页生成器。
- 一人公司经营日报。
- 内容对标监控器。

### OS 售后持续收入

一人公司系统不是一次性软件。卖出系统后，应继续设计可复购、可续费、可扩展的收入层：

- 行业 Agent 包：电商运营包、本地生活包、知识付费包、私域客服包、B2B 销售包、老板助理包。
- 岗位 Agent 增购：销售、客服、内容、财务、审计、HR、技术运维、数据分析等角色按需扩展。
- Skill 市场：内容对标、评论线索识别、报价页生成、微信摘要雷达、发票/收款对账等单项技能可单独售卖。
- 模板订阅：行业 SOP、内容日历、销售话术、交付清单、周报/月报模板按月更新。
- 运维续费：配置中心托管、模型路由优化、数据备份、任务异常监控、安全审计。
- 陪跑服务：客户买 OS 后，继续购买 30/60/90 天经营陪跑。
- 私有化/企业版：给有数据安全要求的客户做本地部署、角色定制、权限审计和内部知识库接入。

产品原则：系统本体负责“跑起来”，行业包和 Skill 负责“更适配”，运维和陪跑负责“持续跑下去”。

## 每日经营动作

Jarvis 每天必须输出：

- 今日经营目标。
- 今日内容选题。
- 今日销售触达对象。
- 今日付款入口检查。
- 今日客户/线索状态。
- 今日阻塞。
- 明日动作。

## 安全边界

- 不自动群发。
- 不自动回复客户。
- 不伪造成交。
- 不登记未到账收入。
- 对外发布和触达必须 CEO 确认。

## 下一步能力

优先做“微信只读私域雷达”：

- 监听微信消息。
- 总结重要消息。
- 提取线索和待办。
- 生成客户画像。
- 发给 CEO 确认。
