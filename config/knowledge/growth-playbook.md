# 增长方法论

## 一、AARRR 模型（海盗指标）

| 阶段 | 指标 | 对应动作 |
|------|------|---------|
| **获客** (Acquisition) | 曝光→点击 | SEO、内容分发、广告 |
| **激活** (Activation) | 点击→使用 | 落地页优化、首次体验 |
| **留存** (Retention) | 使用→回来 | 内容质量、社群运营 |
| **变现** (Revenue) | 用户→付费 | 产品定价、转化漏斗 |
| **传播** (Referral) | 用户→推荐 | 裂变机制、口碑传播 |

## 二、增长实验框架

### ICE 评分法
为每个增长实验打分：
- **I**mpact（影响力）：1-10 分
- **C**onfidence（信心）：1-10 分
- **E**ase（容易程度）：1-10 分

总分 = I × C × E / 100

> 优先做高分实验，快速验证，失败就换

### 实验模板
```
实验名称：xxx
假设：如果我们 [做xxx]，[指标] 会提升 [N%]
实验方法：[具体做什么]
成功标准：[什么数据算成功]
周期：[X 天]
结果：[成功/失败/待定]
学到了什么：[结论]
```

## 三、渠道增长策略

### 搜索流量（长期价值）
- 小红书 SEO：标题关键词 + 正文关键词
- 抖音搜索：口播关键词 + 字幕关键词
- 百度/知乎：长尾问答内容

### 社交流量（爆发力）
- 追热点：24 小时内响应
- 蹭话题：参与平台活动
- 互动裂变：评论区引导、投票、问答

### 私域流量（复利效应）
- 公域引流 → 微信/社群
- 社群运营 → 复购/传播
- 1 个私域粉丝 ≈ 100 个公域粉丝的价值

## 四、内容增长杠杆

### 10x 内容法则
不要做「比别人好一点」的内容，要做「好 10 倍」的内容：
- 更深度（别人写 500 字，你写 3000 字深度解析）
- 更实用（别人讲概念，你给模板/工具/清单）
- 更独特（别人复述知识，你给独家案例/数据）
- 更好看（别人纯文字，你给图表/动画/实拍）

### 内容复利公式
```
短期爆款 × 长期价值 = 内容复利

短期爆款：追热点、情绪共鸣、反差冲击
长期价值：教程、工具、方法论（持续被搜索）
```

## 五、数据驱动增长

### 北极星指标
选择 **1 个** 最重要的指标作为团队核心目标：
- 内容型产品：周活跃用户数（WAU）
- 电商型产品：月 GMV
- SaaS 型产品：月度活跃订阅数（MAS）

### 增长仪表盘
每周跟踪：
1. 北极星指标趋势
2. 渠道效率（各渠道 ROI）
3. 内容效率（篇均互动、发布→爆款率）
4. 转化漏斗（每个环节的转化率）
5. 用户反馈（NPS、评论关键词）
