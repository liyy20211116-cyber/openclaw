# 抖音运营知识库

## 算法逻辑
- 抖音推荐 = 内容质量 × 互动数据 × 用户匹配
- 核心指标：完播率 > 点赞率 > 评论率 > 转发率
- 新号冷启动：前5条视频决定账号标签
- 破播放池：200 → 1000 → 5000 → 10000 → 50000

## 前3秒钩子公式
1. **反常识**："你信不信，我的AI员工也有工资单？"
2. **数字冲击**："5万行代码，9个AI员工，1个人的公司"
3. **疑问悬念**："龙虾AI爆火，但99%的人用错了"
4. **利益承诺**："看完这条视频，你也能搭一个AI助手"
5. **冲突对比**："别人花钱雇人，我给AI发工资"

- 周末适合发日常/轻松内容

## 评论区运营

- 置顶评论放核心内容补充或互动问题
- 引导关注的话术："关注我，下条更精彩"
