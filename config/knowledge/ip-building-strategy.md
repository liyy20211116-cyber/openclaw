# IP 打造内容策略知识库

> 供 AI Agent 生成内容时参考的核心策略

## 品牌定位

**一句话定位**：从零用代码搭建 AI 一人公司操作系统的技术型 CEO
**账号名称**：FY003一人公司 / AI公司CEO日记
**差异化标签**：5万行代码 | 9个AI Agent | Token经济体系 | 桌面端OS

## 目标受众

1. 对 AI 一人公司感兴趣的创业者/准创业者
2. 技术背景的 AI 工具爱好者
3. 关注 OPC/超级个体趋势的职场人
4. AI Agent 开发者和爱好者

## 核心差异化卖点

| 卖点 | 说明 |
|------|------|
| 自研代码 | 不是教你用工具，是教你"造工具"，5万行自研代码 |
| 多Agent协作 | 9个Agent = 9个虚拟部门经理，能协作执行复杂任务 |
| Token经济 | Agent有预算、有工资、有审计，像管真人一样管AI |
| 记忆系统 | Agent有长期记忆，能记住之前的对话和决策 |
| DAG工作流 | 支持复杂任务编排，不是简单的顺序执行 |
| 桌面端产品 | 不是概念PPT，是可以下载运行的实际产品 |

## 内容风格指南

- **人设**：技术CEO，既懂代码又懂商业，务实不浮夸
- **语气**：专业但不枯燥，偶尔幽默，多用比喻让技术概念通俗化
- **视觉**：科技感 + 极简风，深色主题截图，代码高亮
- **禁忌**：不吹牛、不贩卖焦虑、不做标题党（但标题要有钩子）

## 选题方向

### S级选题（必拍）
1. 「一个程序员写了5万行代码，造了个AI公司操作系统」— 人设起号
2. 「我给AI员工发工资，它们靠绩效吃饭」— Token经济
3. 「龙虾AI？我直接造了9只！」— 蹭热点
4. 「AI审计官每天偷偷查其他AI有没有摸鱼」— 趣味
5. 「一人公司日常：CEO开会，到场的全是AI」— 日常

### A级选题（强推）
6. 「比龙虾更强！我的AI操作系统架构解析」— 技术科普
7. 「AI自动帮我写周报、查竞品、算ROI」— 实操
8. 「从0到1搭建AI一人公司的完整路线图」— 干货
9. 「AI Agent有记忆！它记得我3天前说的每句话」— 技术展示
10. 「政策红利来了！一人公司有多少扶持？」— 时事

### B级选题（储备）
11. 「AI帮我做了份销售漏斗分析，准确率高得离谱」
12. 「一个人管理9个AI部门的一天」— CEO日记Vlog
13. 「AI增长官帮我写小红书文案，我给它打分」
14. 「AI面试AI：让审计Agent审查增长Agent的内容」
15. 「5万行代码里最骄傲的100行」

## 各平台发布规范

### 抖音
- 时长：30秒-3分钟
- 最佳发布时间：周五/周六 20:00-22:00
- 前3秒必须有钩子
- 必须加字幕和话题标签
- 每天1条

### 小红书
- 图文/视频笔记均可
- 标题20字以内，用分隔符
- 正文600-1000字，多用emoji
- 底部带5-8个话题标签
- 隔天1条

### B站
- 时长：5-15分钟深度内容
- 每周1-2条
- 适合技术架构解析、代码walkthrough
- 封面要有科技感
