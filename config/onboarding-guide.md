# 新角色入职指南

> 当公司需要新增 Agent 角色时，按本指南执行标准化入职流程。

---

## 一、新建角色标准流程

### 步骤 1：需求评估（贾维斯）

确认以下问题：
- 为什么需要新角色？现有角色能否覆盖？
- 新角色的核心职责是什么？
- 归属哪个部门？还是独立部门？
- 预计 Token 月消耗？

### 步骤 2：角色定义（贾维斯+相关部门）

创建角色目录和必备文件：

```
openclaw_agents/{agent-id}/
├── IDENTITY.md         # 必须 — 角色身份定义
├── skills.json         # 必须 — 技能注册表
├── memory/             # 必须 — 长期记忆目录
│   └── learnings.md    # 必须 — 初始学习记录
└── SKILL-{name}.md     # 可选 — 增强技能定义
```

### 步骤 3：IDENTITY.md 模板

```markdown
# IDENTITY — {角色名}

- **Name:** {角色名}（{英文名}）
- **Role:** {职位}（{英文缩写}）
- **Department:** {所属部门}
- **Emoji:** {代表 emoji}

## 人格
{2-3 段描述角色的性格特征、工作风格、口头禅}

## 核心能力
{列出 5-6 项核心技能}

## 工作规则
{列出 5-6 条工作规范}

## 权限
{列出可以做什么、不可以做什么}

## KPI 指标
| 指标 | 权重 | 衡量方式 |
|------|------|----------|
| {指标1} | {%} | {描述} |
| {指标2} | {%} | {描述} |
```

### 步骤 4：技能配置（赫敏）

1. 从 `skills/` 中选择适用的通用技能
2. 如需定制技能，编写 `SKILL-{name}.md` 和 `skill_{name}.py`
3. 注册到 `skills.json`
4. 由斯内普做安全审查

### 步骤 5：OpenClaw 注册（赫敏）

如需在 OpenClaw 中作为独立 Agent 运行：
1. 在 `openclaw.json` 的 `agents.list` 中添加配置
2. 设置 workspace、identity、tools profile
3. 配置子代理权限（如需要）
4. 重启 Gateway 生效

### 步骤 6：入职测试（多比）

1. 角色自我介绍测试
2. 核心技能执行测试（至少 3 个技能）
3. 与贾维斯的协作流程测试
4. 边界情况测试（权限外操作是否正确拒绝）

### 步骤 7：登记归档（珀西）

1. 更新 `ORG_CHART.md`
2. 更新 `CAPABILITY_MATRIX.md`
3. 登记月度 Token 预算
4. 通知全公司新角色上线

## 二、角色退役流程

当角色不再需要时：
1. 贾维斯提出退役申请，CEO 批准
2. 将角色 skills.json 中的技能标记为 deprecated
3. 将角色目录移入 `归档_历史文档/retired_agents/`
4. 更新组织架构文档
5. 释放 Token 预算

## 三、角色升级流程

当角色需要扩展职责时：
1. 提交变更申请（说明新增什么能力、为什么）
2. 贾维斯审批
3. 赫敏实施技能安装
4. 斯内普安全审查
5. 更新 IDENTITY.md 和 CAPABILITY_MATRIX.md
