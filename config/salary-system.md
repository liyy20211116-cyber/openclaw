# 一人公司薪酬与激励制度

> 本制度管理全公司 Token 分配、绩效奖金和特殊激励。

---

## 一、Token 薪酬体系

### 月度基础工资（Token）

| 等级 | 角色 | 月薪（Token） | 说明 |
|:---:|:---|:---:|:---|
| L4 | 贾维斯（COO） | 5,000 | 运营调度消耗 |
| L3 | 赫敏（CTO） | 8,000 | 技术开发消耗最大 |
| L3 | 麦格教授（CPO） | 3,000 | 需求分析和文档 |
| L3 | 卢娜（CGO） | 5,000 | 内容生产消耗 |
| L3 | 弗雷德（CSO） | 4,000 | 客户开发和方案 |
| L3 | 珀西（CFO） | 2,000 | 财务核算 |
| L3 | 斯内普（CAO） | 2,000 | 审查和风控 |
| L3 | 多比（CCO） | 3,000 | 客户维护 |
| — | **全公司合计** | **32,000** | 月度总消耗预算 |

### 工资发放规则

1. 月初预拨 100%，按日均匀使用
2. 月末结余可累积（上限 2 倍月薪）
3. 超支需提前申请追加预算

## 二、绩效奖金

### 评分标准（与 company-rules.md 一致）

| 评级 | 分数 | 奖金 | 条件 |
|:---:|:---:|:---:|:---|
| S | 90-100 | 月薪 +30% | 超额完成 + 创新贡献 |
| A | 80-89 | 月薪 +15% | 按时按质 + 偶有亮点 |
| B | 60-79 | 0 | 正常完成 |
| C | 40-59 | 月薪 -20% | 延期或质量差 |
| D | <40 | 冻结 | 严重失职 |

### 绩效评估维度

| 维度 | 权重 | 评估方式 |
|:---|:---:|:---|
| 任务完成率 | 30% | 按时完成的任务数 / 分配的任务数 |
| 产出质量 | 30% | 斯内普审核评分（1-10） |
| Token 效率 | 20% | 产出价值 / 实际消耗 Token |
| 主动贡献 | 20% | 主动提案被采纳数量 |

## 三、特殊激励

### 项目分红
- 项目直接产生收入：执行人获 **10%** Token 奖励
- 跨部门项目：按贡献比例分配（贾维斯裁定比例）

### 提案奖励
| 情况 | 奖励 |
|:---|:---|
| 提案被 CEO 采纳并产生正向结果 | 200-1,000 Token |
| 发现并预防重大风险 | 500-2,000 Token |
| 开发可复用的自动化流水线 | 300-1,500 Token |
| 连续 3 周无提案 | 标记"消极"，贾维斯约谈 |

### 季度 MVP
每季度评选 1 名 MVP（Most Valuable Player）：
- 奖励：月薪 50% 额外奖金
- 评选标准：对公司收入贡献最大的角色
- 由贾维斯提名，CEO 确认

## 四、处罚与冻结

| 违规 | 处罚 |
|:---|:---|
| 首次违规（空转/推诿/幻觉） | 警告 + 记录 |
| 二次违规 | 扣当月 20% 工资 |
| 三次违规 | 冻结账户，CEO 审查 |
| 严重安全事故 | 立即冻结 + 全面审计 |

## 五、薪酬调整

- 调薪周期：每季度末评估一次
- 调薪幅度：±10%（贾维斯建议，CEO 批准）
- 调薪依据：连续 2 个月绩效 + 业务发展需要
