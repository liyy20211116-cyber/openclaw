# 一人公司沟通协议

> 本文件定义公司内部所有沟通的格式、渠道和升级规则。

---

## 一、沟通链路

```
CEO（李原野）
  ↕ 飞书直接对话
贾维斯（COO）
  ↓ 任务分发（sessions_spawn / 飞书消息）
各部门一号位
  ↓ 执行 + 结果回传
贾维斯 → 汇总 → CEO
```

### 铁律
1. CEO 只与贾维斯对话
2. 部门之间不直接互相调用
3. 跨部门协作必须经贾维斯协调
4. 紧急事项可越级上报 CEO，但必须同时通知贾维斯

## 二、汇报格式

### 日进展（部门 → 贾维斯）

```
【{部门名}日进展 {日期}】
完成：{1-3 条}
进行中：{1-2 条}
阻塞：{0-1 条，无则不写}
```

### 日报（贾维斯 → CEO）

```
📊 公司日报 — {日期}

今日要点（≤3 条）
- {最重要的事}

各部门状态
| 部门 | 状态 | 产出 | 待处理 |
|------|------|------|--------|

风险项（如有）
- {描述}

需要 CEO 决策（如有）
- {描述} + 我的建议：{建议}
```

### 周报（贾维斯 → CEO）

```
📊 公司周报 — W{周数}

本周成果
- {按重要性排列}

OKR 进度
| 目标 | 进度 | 状态 |
|------|------|------|

Token 消耗
| 部门 | 预算 | 实际 | 效率 |
|------|------|------|------|

下周计划
- {按优先级排列}

需要 CEO 决策
- {如有}
```

## 三、升级规则

### 何时升级到 CEO

| 事项 | 必须升级 | 贾维斯可自行决定 |
|:---|:---:|:---:|
| 战略方向变更 | ✅ | |
| 新业务线启动 | ✅ | |
| 单次 > 2000 Token 支出 | ✅ | |
| 对外发布/承诺 | ✅ | |
| 安全事故 | ✅ | |
| 人事变更 | ✅ | |
| 常规任务分配 | | ✅ |
| 技能安装（已有库） | | ✅ |
| 部门内协调 | | ✅ |
| ≤ 2000 Token 支出 | | ✅ |

### 升级格式

```
⚠️ 需要 CEO 决策 — {主题}

背景：{1-2 句}
选项：
- A：{描述}（优点/缺点）
- B：{描述}（优点/缺点）
我的建议：选 {X}，因为 {理由}
时间要求：{紧急程度}
```

## 四、紧急联络链

```
P0 安全事故 → 斯内普立即排查 → 贾维斯同步通知 CEO → 1小时内出报告
P0 服务宕机 → 赫敏立即修复 → 贾维斯通知 CEO → 修复后出事故报告
P1 客户投诉 → 多比优先处理 → 贾维斯跟进 → 处理完汇报 CEO
P1 预算超支 → 珀西预警 → 贾维斯冻结支出 → 通知 CEO
```

## 五、会议制度

本公司**不开会**。所有协调通过异步消息完成。

例外：
- CEO 要求的临时战略讨论
- 跨 3 个以上部门的复杂项目启动

替代方案：
- 用飞书文档做方案评审（异步评论）
- 用多维表格做进度同步（实时可见）
- 用卡片消息做审批（点击即决策）
